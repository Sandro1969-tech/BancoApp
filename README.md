# BancoApp 🏦

Aplicação simples de banco desenvolvida em **TypeScript**, como parte do desafio da DIO proposto pela expert Nathally Souza.  
O objetivo é praticar conceitos de orientação a objetos e versionamento com Git/GitHub.

---

## 🚀 Funcionalidades
- Criar clientes e contas
- Depositar valores
- Sacar valores
- Consultar saldo
- Gerenciar contas dentro de um banco

---
